Kyle Media — Privacy Policy

Last updated: October 16, 2026

Who uses this app

Kyle Media is a private tool used by Kyle Koehn for his own media projects. It is not offered as a public service.

What Google data it accesses

With the owner's consent, the Drive connection uses the limited drive.file permission to read and manage files created or opened through the app. It stores and restores selected media, project files, verification records, and job data in a separate private media workspace. The canonical hymn archive is outside this writable workspace.

A separate YouTube connection reads the owner's channel, video, and playlist information and manages uploads and playlist membership. It can remove superseded videos when the owner has selected that revision policy. New uploads are private by default; public publication requires the owner's explicit authorization.

How data is processed and stored

Project data is processed on the owner's computer or private cloud workers configured by the owner. Selected media and recovery records are stored in the owner's private Drive folders and YouTube library. Source code and compact project records are kept in private GitHub repositories.

API keys and Google authorization tokens are kept outside source repositories and media snapshots, in protected local settings or the selected cloud environment's secret settings. They are not published on this website.

Owner-selected scripts or audio may be sent to configured narration or transcription services to perform the requested task. Cloud hosts and service providers process data under their own terms and settings; their data-use rules depend on the service and tier selected by the owner.

The toolkit uses Google user data only for the owner's requested media workflows. It does not sell that data, use it for advertising, or use it to train generalized AI models.

Kyle Media's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removing access

The owner controls retention of local files, private Drive snapshots, and YouTube videos. Previous versions may be retained for recovery; configured YouTube revision cleanup can remove superseded videos.

The owner can revoke Google access at myaccount.google.com/permissions and remove saved authorization from local or cloud settings. Revoking access stops future authorized requests; it does not by itself delete files already stored in the owner's accounts or working directories.
